# 🍪 Cookie Porter

Export and import browser cookies as JSON files.

## Installation

| Step | Action                                            |
| ---- | ------------------------------------------------- |
| 1    | Extract the ZIP file                              |
| 2    | Open `chrome://extensions` or `edge://extensions` |
| 3    | Enable **Developer mode**                         |
| 4    | Click **Load unpacked**                           |
| 5    | Select the `cookie-porter` folder                 |

> Do not delete the folder after installation.

## Export

1. Open a website.
2. Open Cookie Porter.
3. Select a scope.
4. Click **Export as JSON**.

## Import

1. Open Cookie Porter.
2. Go to **Import**.
3. Select a JSON file.
4. Click **Import Cookies**.

## Security

* JSON files are not encrypted.
* Keep backups private.
* No external servers are used.
