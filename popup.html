What does it do?
Export your cookies to an encrypted JSON file that you can save to a USB drive or cloud storage, and import them after formatting or on another computer.

Export modes
· Current tab — only the open domain
· Domain — any site you specify
· All — all browser cookies

Security
Cookies never leave your computer except in the file you save. The extension has no external server.
